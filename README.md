\# GuessTheFlag



A small flag-guessing game built with SwiftUI while working through 100 Days of SwiftUI by Paul Hudson.



The project was created as a practical learning exercise to develop my understanding of SwiftUI, application state, user interaction and conditional logic.



\## What it does



\- Displays three country flags

\- Prompts the player to identify a specific country

\- Provides immediate feedback on the selected answer

\- Keeps track of the player's score

\- Presents a series of questions during a game



\## Technologies



\- Swift

\- SwiftUI

\- Xcode



\## What I learned



This project provided practical experience with:



\- SwiftUI views and layouts

\- Managing application state

\- Handling user interaction

\- Working with arrays and randomised selections

\- Conditional logic

\- Alerts and user feedback

\- Structuring a simple SwiftUI application
